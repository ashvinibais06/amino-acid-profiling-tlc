# amino-acid-profiling-tlc
A biochemistry laboratory project exploring amino-acid separation using thin-layer chromatography (TLC) and retention factor (Rf) analysis.
Amino-Acid Profiling Through Thin-Layer Chromatography (TLC)

Overview

This project focuses on the separation and analysis of amino acids using thin-layer chromatography (TLC). It explores how amino acids behave on a stationary phase and how their movement can be studied using retention factor (Rf) values.

Objectives

- Understand the fundamental principles of thin-layer chromatography.
- Study the separation of amino acids based on their interactions with the stationary and mobile phases.
- Calculate and interpret Rf values to compare the movement of different compounds.
- Explore the role of chromatography in biochemical analysis.

Principle

Thin-layer chromatography is a separation technique in which compounds move across a coated plate under the influence of a mobile solvent phase. Differences in their interactions with the two phases cause them to travel different distances.

The retention factor is calculated as:

Rf = Distance travelled by the compound / Distance travelled by the solvent front

Methodology

1. Prepare the TLC plate and mark the starting line.
2. Apply the amino-acid samples at the marked positions.
3. Place the plate in a suitable developing chamber containing the solvent.
4. Allow the solvent to move through the plate.
5. Visualize the separated spots using an appropriate detection method.
6. Measure the distances and calculate Rf values.
